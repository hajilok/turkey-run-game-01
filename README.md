# FEATHERBREAK: The Great Thanksgiving Escape — 4-Stage Stealth-Action Turkey Runner

Outsmart **Farmer Barnaby**, dodge roaring **425°F cast-iron roasting ovens** and spinning **Damascus carving knives**, slip inside hollowed pumpkins and copper stockpots to vanish from his lantern beam, flick harvest acorns with the mouse to slam oven doors or bonk hanging pots onto his straw hat, and race **1,200 meters** from the **Golden Farmyard** through the **Harvest Barn**, **Applewood Pantry**, and **Roasting Kitchen** to the **Freedom Gate**!

Built for the [`turkey-run-game-01`](https://make.fun/bounty/turkey-run-game-01?ref=41fw6r6c) competition on [make.fun](https://make.fun/r/41fw6r6c).

## Controls
- **Move**: `A` / `D` or `←` / `→`
- **Jump & Feather-Flutter**: `W` / `↑` / `Space` (hold in mid-air to glide)
- **Duck / Hide in Cover**: `S` / `↓` / `E` inside pumpkins, haystacks, flour sacks, or copper pots
- **Gobble-Dash**: `Shift` or `Right-Click` (invulnerable burst + Close-Call graze bonus)
- **Toss Harvest Acorn**: Aim & `Left-Click` (distract Farmer Barnaby, drop hanging pots, or slam oven doors)
- **Pause / Mute**: `P` or `Esc` to pause, `M` to toggle procedural Web Audio

## Play Locally
```bash
node serve.ts
# Open http://127.0.0.1:8080 in Chrome (100% offline, zero external requests)
```

## Build Dossier

mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
